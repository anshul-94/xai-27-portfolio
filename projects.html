CareerPilot AI

CareerPilot AI is an Agentic AI-powered career intelligence platform that helps students improve their resumes, discover jobs, prepare for interviews, and receive personalized career guidance using multiple AI modules.

Problem Statement

Students and job seekers often struggle to align their resumes with industry expectations, identify their skill gaps, prepare for behavioral/technical interviews, and navigate the complex job market. CareerPilot AI solves this by acting as an end-to-end intelligent career mentor.

Features

  • AI Resume Analyzer: Automated feedback and scoring to optimize resumes against job descriptions.
  • Resume Builder: Step-by-step guidance for building industry-standard professional resumes.
  • Career Assessment: In-depth evaluation of skills and interests to map out potential career paths.
  • AI Career Coach: 24/7 conversational agent providing personalized mentorship and guidance.
  • AI Job Finder: Smart job search matching candidates with the most relevant opportunities.
  • Skill Gap Analysis: Actionable insights pointing out missing skills and resources to acquire them.
  • Resume Version History: Version tracking to save, manage, and iterate on different resume drafts.

Workflow

Resume → AI Analysis → Career Suggestions → Job Search → Personalized Recommendations

Food Delivery Time Prediction

Built an end-to-end Machine Learning regression model that predicts food delivery time using real-world delivery data. The project includes preprocessing, feature engineering, model training, and evaluation.

Features

  • Processed 45,000+ records: Real-world delivery data handled for high prediction reliability.
  • Data Cleaning: Handled missing values, outliers, and incorrect data types.
  • Feature Engineering: Extracted time and distance metrics to boost predictive power.
  • ColumnTransformer Pipeline: Built robust pipelines for preprocessing categorical and numerical features.
  • Random Forest Regressor: Trained and optimized machine learning models for accurate forecasting.
  • Model Evaluation: Evaluated using metrics like MAE, MSE, and R-squared to ensure precision.
  • Joblib Model Saving: Serialized the trained model pipeline for seamless deployment and reuse.

Workflow

Dataset → Preprocessing → Feature Engineering → Model Training → Prediction

AI Learning Assistant (Voice + RAG)

Developed an AI-powered learning assistant that lets students upload PDFs and notes, ask questions through voice or text, and receive context-aware answers using Retrieval-Augmented Generation (RAG).

Features

  • PDF Upload: Easily upload textbooks, notes, and documents for learning.
  • Voice Input: Speak naturally to ask questions using integrated speech-to-text.
  • Voice Output: Hear answers read aloud with high-quality natural text-to-speech.
  • RAG Pipeline: Uses Retrieval-Augmented Generation to ground answers in uploaded materials.
  • Semantic Search: Performs relevant context retrieval based on query meaning.
  • FAISS Vector Database: Extremely fast indexing and search of document embeddings.
  • Context-aware Answers: Delivers precise answers sourced from the uploaded documents.

Memory-Based AI Chatbot

Built an AI-powered chatbot that remembers previous conversations, allows users to upload different file types, and answers questions using Retrieval-Augmented Generation (RAG). The chatbot supports multiple document formats and provides context-aware responses with persistent conversation memory.

Features

  • Persistent Chat Memory: Remembers previous conversations to provide context-aware and personalized responses.
  • PDF Question Answering: Upload PDF documents and ask questions directly from their content.
  • CSV & Excel Analysis: Analyze spreadsheets, generate insights, and answer data-related questions.
  • Image Understanding: Upload images and ask questions about objects, text, or visual content.
  • WhatsApp Chat Analysis: Upload exported WhatsApp chats to generate summaries, insights, and conversation analysis.
  • Retrieval-Augmented Generation (RAG): Retrieves relevant information before generating accurate responses.
  • Semantic Search: Finds relevant information using embeddings instead of keyword matching.
  • FAISS Vector Database: Stores and retrieves document embeddings efficiently for fast responses.
  • Ollama LLM: Generates natural and intelligent responses using a locally hosted language model.

Workflow

Upload File / User Message → Document Processing → Chunking & Embeddings → FAISS Vector Search → Retrieve Relevant Context → Ollama LLM → Context-Aware AI Response
